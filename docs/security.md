# 安全与隐私边界

关联 REQ-006/007/010–016/021/022/028/029/030、NFR-001/002/008。

## 1. 信任模型

Markdown、文件名、链接、图片、外部修改和本地恢复/历史索引均视为不可信输入。renderer 不拥有真实文件路径对应的写权限，主进程负责路径、身份、大小、格式、版本和会话授权。相同用户权限的恶意本机进程可能在最后一次核对后替换文件；本应用不承诺与任意进程共享文件系统事务锁。

原始 Markdown 是保存来源，预览 HTML 不是正式内容。正文不发送到远程服务，无账号、遥测或云同步。第三方依赖更新与公开发布的许可/安全复查独立进行。

## 2. Electron 与 IPC

BrowserWindow 固定 `nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`、`webSecurity: true`。preload 只暴露冻结的业务 API，当前 26 个方法，包括 25 个 invoke 方法和一个事件订阅；清单见[契约](contracts.md)。无通用 IPC、任意路径读写、Node、shell 或执行命令能力。

每个特权入口核对 main frame、可信 origin、owner 和其业务参数；需要会话的请求验证完整 docId/epoch，拒绝未知字段和不合规 UUID、token、尺寸。文档级操作不通过 renderer 传入任意路径。保存及还原使用 requestId、快照和版本绑定；重放结果也不能跳过调用方和 payload 校验。

导航、新窗口和权限请求默认拒绝。生产窗口只加载内部 `inknest://app/`，不采用环境变量中的开发 URL。资源协议独立；外部网络不能通过页面自动请求。

## 3. 预览与 CSP

markdown-it 关闭通用原始 HTML，只解析[兼容清单](markdown.md)中无属性格式标签、受限折叠与空锚点语法；DOMPurify 使用标签/属性白名单。文内显式锚点是解析器识别的受限语法，生成应用自己的 ID，不开放任意 HTML。表格滚动容器、标题焦点、图片交互和搜索排除标记在净化后由应用生成，不让 Markdown 提供任意 class/style/事件。

CSP 限制脚本、连接、资源及样式来源；CodeMirror 通过本次窗口生成的 nonce 使用所需样式，不关闭 CSP 或沙盒。图片先在惰性 template 中提取原目标并移除 src，授权、替换为资源 URL、净化后才进入活动 DOM，避免原始 URL 自动联网。

Mermaid 配置由应用固定为 strict，文档不能提供初始化/YAML 配置；不绑定图表点击回调。输出再次按 SVG 配置净化，移除链接、图片、foreignObject、脚本和动画。生成样式只接受当前图表 ID 下的选择器及有限声明，禁止外部 URL、CSS 自定义属性和布局逃逸；最终样式使用窗口 nonce。图表生成过程仍受原 CSP 与网络阻断约束。

KaTeX 固定 trust:false、strict:error、MathML 输出和宏展开上限，每式独立宏空间；再次净化 MathML，移除链接及可执行标注。代码高亮输出只允许 span/class。复制由用户点击/键盘触发浏览器剪贴板写入，不开放读取剪贴板或新增 IPC。以上内容不得回写源码，不扩大本地图片或远程资源授权。

## 4. 被动图片与主动链接

被动图片只允许当前文档目录及其真实子目录内的 PNG/JPEG/WebP/GIF。规范路径、链接、身份和版本均需复核。父目录、绝对路径或越界资源不会仅凭 Markdown 自动获得权限；不存在额外目录授权接口。

每图压缩字节 ≤20MiB；解码画布 ≤40MP，动画按逻辑画布 × 帧数累计；每会话元数据及响应读取总预算 100MiB、最多 2000 个资源能力。sharp 读取完整压缩输入的元数据，不解码像素；后缀、签名、实际格式一致。GIF 取逻辑画布与报告帧尺寸的较大值。APNG、SVG、远程图片与 data URL 拒绝。PNG 容器检查不等于所有 CRC/像素完整性验证；浏览器解码失败显示占位。

资源 URL 绑定 owner、ref、单文件能力和实际身份；响应再次核对、计费，关闭/迁移时撤销，不能靠另存为重置读取预算。历史只读展示不能借用不属于它的图片权限。

主动链接来自明确用户操作，通过 `document:link` 路由。拒绝控制字符、UNC/网络路径、未知协议和无效编码；百分号只解码一次。Markdown 目标读取前复核真实身份，打开/激活独立标签；本地图片显式授权单一目标并进入查看器，不扩张整个资源根。目录交给系统打开，普通附件只在文件管理器定位；HTTP/HTTPS/mailto 交给系统。来源失效、活动代数或路径变化取消旧请求。

系统打开的最终派发与外部进程改路径之间仍存在竞争窗口，不能声称消除了同账号恶意进程攻击。

## 5. 保存、恢复与历史

同目标写入串行；不可变快照、token、真实字节及身份检查由 main 执行。另存为只通过系统 picker 授权本次目标，覆盖默认取消。恢复/历史采用经过 schema、文件类型、大小及 hash 验证的索引；未知或损坏内容不自动恢复、不形成删除授权。

历史还原请求不提供路径、历史正文或 force。main 重新校验目标，强制保护当前内容，阻止同 ref 生命周期操作与历史清理交叉；失联重放只查询同一请求结果。完整规则见[持久化协议](persistence.md)。

## 6. 演示、搜索与主题

演示只控制所属受信窗口的全屏状态，来源失效退出；不开放任意窗口 ID、命令或路径。生产代码没有受控全屏测试开关，测试替身只在测试进程中装配。

搜索使用 renderer 已有的展示文本或源码，替换进入原 CodeMirror 事务，不新增文件/网络能力。主题只能读取当前配置并写入 light/dark 枚举，配置路径由主进程固定。

## 7. 安全测试与日志

自动化覆盖恶意 Markdown、路径穿越、畸形图像、跨 owner/ref 请求、旧 token、乱序/重复回执、损坏索引和写入失败。安全测试保留完整 API 白名单；新增业务方法必须同步契约和该白名单，不放宽为“包含若干已知方法”。

应用日志不应包含正文、凭据或完整用户文档。反馈问题时移除机器路径、会话标识及截图中的个人内容。兼容性与可靠性边界见[已知限制](known-issues.md)。


新建只增加固定零参数 createDocument，不接收路径、正文、docId、模板或配置。main 同步检查窗口所有权、20 标签容量及生命周期门控；无路径会话不授权进程 cwd、被动图片或磁盘历史。原生首存选择器只授权最终选定目标，建议目录不产生额外权限。关闭丢弃仍要求主进程确认和持久标记，renderer 不能用 dirty 布尔量绕过保护。
