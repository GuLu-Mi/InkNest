# Markdown 显示与兼容性

关联 REQ-002/004/005/007/016/021/023/024/029/030、NFR-001/002/005/006/007/008。本文对应当前源码；已发布版本以对应标签下的文档为准。

普通阅读、历史预览、恢复草稿预览和全屏演示使用同一套渲染规则。编辑模式始终显示 Markdown 源码；预览结果不参与保存，不自动格式化文件。Markdown 存在不同方言，本应用支持范围如下。

完整可阅读样例见 [Markdown 完整展示](examples/markdown-showcase.md)，包含本地图片、清单内各类图表、公式与全部常用高亮语言。

## 支持清单

| 内容 | 写法与行为 |
| --- | --- |
| 基础 Markdown | ATX/Setext 标题、段落、软/硬换行、分隔线、引用、嵌套有序/无序列表、强调、粗体、转义、行内代码和围栏/缩进代码 |
| 表格、删除线 | 管道表格、左/中/右对齐、`~~删除线~~`；宽表格局部横向滚动 |
| 任务列表 | `- [ ]` / `- [x]`，只读复选框；修改状态需要编辑源码 |
| 链接与图片 | 内联/引用式链接、裸网址和邮箱、标题锚点、受限显式锚点、本地图片；主动链接和图片权限见[交互](interaction.md)与[安全](security.md) |
| 代码 | 显式语言标记对应常用语言高亮，复制按钮复制原始代码；未知或超限语言保留纯文本，不自动猜测语言 |
| Mermaid | `mermaid` 围栏绘图，支持流程、时序、类、状态、实体关系、饼、甘特、思维导图、时间线、Git 分支、象限、XY 图、用户旅程等固定版本提供的图型；安全限制见下文 |
| 数学公式 | `$…$`、`\(…\)` 行内公式；`$$…$$`、`\[…\]` 和 `math` 围栏块公式；使用 KaTeX 支持的 TeX 子集 |
| 脚注 | `[^标识]` 与 `[^标识]: 内容`，支持重复引用、单击脚注跳转与返回 |
| 提示块 | 引用首行 `[!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]`、`[!CAUTION]`；分别显示蓝/绿/紫/橙/红色的图标、中文标题与左侧竖线，正文保持正常文字颜色 |
| 文档元数据 | 文档开头 `---` 包围、以 `---` 或 `...` 结束的头部，显示为默认折叠的“文档元数据”；只展示，不执行 YAML 或用它修改应用设置 |
| 定义列表 | 术语下一行 `: 定义` |
| 标记、上下标 | `==标记==`、`H~2~O`、`x^2^` |
| Emoji | `:smile:` 等命名短码；原有 Unicode Emoji 原样保留，不将普通表情标点自动替换 |
| 少量 HTML 写法 | 无属性的 `<br>` / `<br/>`、`<kbd>`、`<sub>`、`<sup>`、`<mark>` 及其结束标签；独立行的 `<details>` / `<details open>`、`</details>`、`<summary>标题</summary>` 支持折叠正文 |

预览高亮使用 highlight.js 的 common 语言集，包括 Bash、C/C++、C#、CSS、Diff、Go、GraphQL、INI、Java、JavaScript、JSON、Kotlin、Less、Lua、Makefile、Markdown、Objective-C、Perl、PHP、Plaintext、Python、R、Ruby、Rust、SCSS、Shell、SQL、Swift、TypeScript、VB.NET、WebAssembly、XML/HTML、YAML 及库提供的别名。

引用式链接的定义行只提供目标，不显示为正文；有对应定义时，`[文字][标识]`、`[标识][]` 和 `[标识]` 都显示为链接，未定义的标识保持原文。受限的独立空锚点仅提供定位目标，阅读时不显示标签源码。裸邮箱可紧接中文冒号、括号等常用标点，代码块和行内代码中的地址保持文字。

代码块按可用宽度自动换行，保留缩进、原有换行及高亮配色。自然高度超过320px时默认限制为320px高的可滚动区域，支持滚轮、触控板和键盘查看后续代码，右下角提供“展开代码/收起代码”；短块不显示该按钮。展开后的按钮随正文滚动保持在该块可见区域的右下角；收起后保持按钮可见。窗口缩放、宽度变化和折叠区展开后重新判断高度，同一预览切换主题保留展开选择。复制始终取得完整原始代码，不包含视觉换行或工具栏文案。

## 图表与公式

Mermaid 流程图使用应用固定的蓝色主题。普通矩形显示为浅蓝圆角节点、蓝色文字和灰色连线，连线文字以胶囊标签显示；深色主题使用深蓝底和浅蓝文字。判断菱形、圆形、圆柱等形状保持语义，较长节点文字自动换行。思维导图使用18px系统字体、蓝色中心节点与柔和的分支分类配色，文字在节点内居中，深色主题有对应配色。其他图型保留各自的分类配色。

正文链接使用亮蓝色并保留下划线；配色不改变链接打开方式。浅色强调色的对比度限制见[已知限制](known-issues.md)。

图表默认适应正文宽度。“原始大小”提供局部滚动，“查看源码”切换图形与源码，“复制”始终复制图表原始代码。深浅主题自动更新图表配色。图表文字由本机绘制，不需要联网。

```mermaid
flowchart LR
  A[打开 Markdown] --> B[阅读图表]
  B --> C[查看源码]
  C --> B
```

公式按本机 MathML 能力排版，不下载字体。美元金额和转义的美元符号保持普通文本；复杂金额或公式边界存在歧义时，用 `\$` 表示美元符号，或用 `\(…\)` 明确标记公式。行内公式不跨换行或代码边界。

XY 图的中文标题需用双引号包围，例如 `title "数量变化"`。

图表语法错误、受限配置、公式不支持的命令或超过限制时，保留该块源码并提示原因；其余正文继续显示。Mermaid 的 `%%{…}%%` 配置指令、图内 YAML 配置头、点击回调、外部图片、任意 HTML 标签和远程样式不开放；普通 `%%` 注释可用。安全过滤可能简化依赖 HTML、图片或自定义样式的图表外观。

| 容量 | 规则 |
| --- | --- |
| Mermaid | 每个活动预览最多 20 张；单图最多 20,000 个字符、500 行、200 条边 |
| 公式 | 每个活动预览最多 200 个；单式最多 8,000 个字符，宏展开上限 1,000，不共享文档间宏状态 |
| 高亮 | 单块最多 32,000 个字符，单次预览累计最多 256,000 个字符；超过仍可阅读、复制 |
| 元数据 | 结束分隔符必须出现在开头的 256 行内；未闭合或超限按普通 Markdown 解析 |
| 大文档 | 文档 >2MiB 时继续按既有规则显示只读纯文本，不执行图表和公式渲染 |

渲染库按需加载，图表逐个生成。切换文档、主题或来源会丢弃旧的异步结果；不会将前一个标签的图表放进当前文档。输入上限用于限制常见高复杂度内容，不保证任意恶意图型的硬实时执行时间。

## 阅读交互

- 普通文字链接沿用 `Command/Ctrl+单击`；脚注引用和返回可直接单击，也可用键盘 Enter/空格。
- 折叠区由摘要行展开；目录定位折叠区里的标题时先展开该区。
- 阅读搜索针对当前显示的内容：包括图表标签、公式可见文字；忽略复制按钮、图表隐藏源码、公式内部标注和关闭的 `details` 正文。代码高度收起不排除后半段代码，定位到被裁切的匹配时自动展开该块。切换源码或展开 `details` 后重新建立搜索索引。编辑搜索始终针对完整源码。
- 代码复制、图表切换和折叠可通过键盘操作；所有操作不改变文档 dirty 状态、撤销栈或历史。

## 保持为源码的内容

不执行任意 HTML、脚本、iframe、表单、嵌入视频/音频或文档提供的样式。不将 MDX/JSX 当作程序运行。不自动支持 Obsidian 双链/嵌入、Dataview、站点模板、插件指令、PlantUML、Graphviz 或其他私有代码围栏；未知代码围栏正常显示和复制源码。

SVG 文件图片与远程内嵌资源仍不加载。应用从 Mermaid 生成并净化的 SVG 是独立的受限输出，不构成对任意 SVG 文件的授权。链接、路径和资源授权规则见[安全与隐私](security.md)。

固定回归样本见 [markdown-compatibility.md](../tests/fixtures/markdown-compatibility.md)。它同时包含成功、错误和受限内容，错误示例用于验证局部降级。
