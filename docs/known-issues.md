# 已知限制

本文对应当前源码；已发布版本的限制以对应标签下的本文为准。InkNest 仍处于开发中，当前不提供完整的目标平台兼容性和正式分发保证。

## 功能范围

- 不提供拖放文件和分屏编辑/预览；新建与无路径恢复需首次保存选择正式位置。整窗退出遇到非空未命名稿会停止退出，需先保存或单独关闭该标签。
- Markdown 支持范围、图表/公式容量和受限语法见[兼容清单](markdown.md)。任务框只读，不支持在预览中点击改写；不承诺所有 Markdown 方言或完整 TeX。
- 非 UTF-8、混合换行或孤立 CR 文件只读，不提供格式转换。有效 UTF-8 的权限/链接只读副本可另存为。
- 首次主题跟随系统；手动选择浅/深后持久化，没有恢复跟随系统的入口，也没有字号、行距和宽度设置页。
- 不保存跨启动的标签、最近文件、窗口位置尺寸和阅读位置。
- 搜索为当前来源的字面匹配，不支持正则或跨文档搜索；替换仅对可编辑源码开放。
- 不识别所有不支持的文件系统，不提供跨进程文件事务锁，不主动跟踪跨目录重命名。

## 保存与恢复

正式文件、恢复草稿和本地历史分别存储。原文件与历史索引不能跨文件原子提交；保存成功后、历史索引发布前崩溃，可能留下已更新原文件和旧历史列表。

自动保存历史在固定时间窗口内合并，不保留每个中间输入状态。恢复入口校验最新快照；最新条目损坏时不会自动回退到更早快照。未知格式、孤立或损坏文件不被当作可信正文。

手动保存可在明确确认后仅本次跳过覆盖前历史；自动保存、关闭保存和历史还原不能跳过。正文已保存但历史失败会独立提示，并暂停后续自动保存。

## 已知问题

- Electron 自动化中出现过恢复错误提示未显示、保存内容与预期不同、替换结果及搜索计数不一致。桌面输入干扰、驱动时序和应用行为的影响尚未区分，问题根因未确定。
- 图片查看器曾出现滚轮未滚动的自动化失败，尚未确定原因。
- 内存占用及反复操作后的内存增长存在超出[性能目标](requirements.md)的情况。

这些问题仍然开放；自动化暂未复现不能视为已经修复。

## 平台与分发

- Windows 11 x64 的安装、升级、卸载、真实文件占用及完整运行兼容性尚未经完整验证；安装器没有 Markdown 文件关联声明。
- macOS 14 arm64 最低系统兼容性尚未经验证。
- 图片查看器的真实触摸板捏合、两平台实体鼠标滚轮及连续手势手感仍待实机验收；合成事件与Electron自动化不能替代设备验证。
- 真实中文输入法、读屏、原生选择器和全屏交互仍需目标平台验证；错误注入和进程强杀不能代替真实磁盘满或断电测试。
- Mac 构建使用 ad-hoc 签名，没有 Developer ID 签名和公证；Windows 安装包未签名。
- 项目为 `UNLICENSED`，不提供自动更新服务。
