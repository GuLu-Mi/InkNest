# InkNest 产品需求规格

本文定义产品范围、功能要求和质量目标。部分能力尚未提供，使用限制见[已知限制](known-issues.md)。

## 1. 定位与用户

一款无需登录、直接使用本地文件的 Markdown 阅读与编辑器。主要面向阅读技术文档、测试说明、项目 README 和个人笔记的用户。核心流程为“打开—阅读—修改—可靠保存—再次打开”。

主要场景：双击说明文档阅读；修改测试步骤后保存；边写 Markdown 边看预览；文件由其他编辑器修改时获得明确反馈；意外退出后找回最近成功备份的内容。

本项目暂不以商业收入、替代所有编辑器或完整兼容所有 Markdown 方言为验收条件。

## 2. 产品边界

明确不纳入当前基线：所见即所得、账号、云同步、多人协作、知识库导入、插件市场、AI 功能、移动端、Linux、Windows ARM、Intel Mac、文件夹树、PDF/HTML 导出、自动更新、公式与 Mermaid、粘贴或拖入图片写入资源目录。

## 3. 平台与默认设置

| 项目 | 规定 |
| --- | --- |
| Windows | Windows 11 x64；最低与当前受支持系统版本纳入实际测试记录 |
| macOS | macOS 14 及以上，arm64（Apple Silicon）；至少验证 macOS 14 和发布时最新兼容版本 |
| 界面语言 | 简体中文；文本集中管理，暂不提供语言切换 |
| 视图 | 新打开已有文件默认阅读；新建文档进入编辑；切换模式保留文档状态 |
| 文档数量 | 单窗口最多20个文档标签；单活动视图，各文档独立保持状态；达到上限拒绝新增并保留全部会话 |
| 自动保存 | 默认开启，依赖独立的恢复、历史及关闭保护；当前无设置开关 |
| 主题 | 跟随系统；另有浅色、深色 |
| 阅读设置 | 字号 16px，范围 12–24px；行高 1.75，范围 1.4–2.0；宽度 1080px，未来设置可选 800 / 960 / 1080px并兼容既有640px值，始终适配窗口 |
| 编码 | 新文件 UTF-8 无 BOM、LF；已有 UTF-8 保留 BOM、统一 LF 或 CRLF、末尾换行状态 |
| 原始 HTML | 默认作为文字显示，不执行、不解析为可交互 HTML |
| 网络 | 文档远程资源默认不加载；不提供远程图片加载开关，可由用户主动在浏览器查看链接 |
| 最近文件 | 最多 20 条，去重，可清空；不保存正文 |
| 自动恢复 | 开启，不能因关闭自动保存而停用 |

UTF-8 非法字节、UTF-16/GBK 等其他编码不开放原位编辑；显示明确提示，可只读查看安全解码结果。混合 LF / CRLF 或含孤立 CR 的文件只读，用户选择“转换为 UTF-8 / 统一换行并另存为”后生成独立文件，不静默覆盖原文件。孤立 CR 不属于支持原位编辑的 LF / CRLF 格式，不能在进入编辑器时被无提示归一化。有效 UTF-8 并不保证原始作者意图可被自动识别，界面不宣称通用编码检测。

格式转换只针对≤2MiB文件，先展示转换预览及替代字符警示，用户确认后另存为不同文件；不承诺自动准确转换任意源编码。超大小文档保持只读并提示使用其他工具。符号链接/可检测硬链接只读，允许另存为普通文件；明确不支持的文件系统限制原位编辑。以上限制不能藏在实现细节中。

当前完整设置、新建、格式转换和最近文件等仍是目标，尚未全部接入；不能从本节默认值推断 UI 已提供对应入口。当前仅提供阅读/编辑视图，不提供分屏。目标中的不支持文件系统识别尚未实现。

| REQ-003 | 标题目录支持ATX/Setext、中文和重复标题；可整体收起、分级折叠，阅读定位正文、编辑定位源码；历史目录绑定所看历史；确定性ID由同一次解析派生并由测试固定 |
| REQ-004 | 常用代码语言高亮、一键复制原始代码、长代码横向滚动；未知语言安全显示纯文本 |
| REQ-005 | 阅读模式搜索渲染后的正文；编辑模式搜索源码并支持替换；分屏模式搜索目标明确可选 |
| REQ-006 | 本地PNG/JPEG/WebP/GIF以文档目录为基准；越界内嵌图显示受限占位，主动图片链接由显式操作授权单个目标；普通点击在应用内查看，支持双指捏合、macOS Command／Windows Ctrl＋滚轮缩放和每次顺时针90°旋转；普通滚轮及双指滑动保持滚动，无拖动平移；旋转仅影响当前查看，不改写文件；图片失败不阻塞正文 |

| REQ-008 | 阅读、编辑、分屏共用文档会话，模式切换和成功保存保留内容、光标、选区、撤销历史 |
| REQ-009 | 新建未命名文档、手动保存、另存为；未命名保存时选择路径，另存为成功后切换正式路径 |
| REQ-010 | 无编辑时保存不改写原文件；编辑后保留既有 UTF-8 BOM、统一换行与末尾换行状态，不自动格式化 |
| REQ-011 | 保存快照排队；保存旧修订不能把新修订标为已保存；状态区分未保存、保存中、已保存、失败、冲突 |
| REQ-012 | 外部更新且本地干净时重载；本地有修改时保留两份并暂停写入，供比较、另存为、明确覆盖或放弃本地版本 |
| REQ-013 | 关闭标签、关闭窗口、退出时保护未保存修改；普通标签切换不关闭文档；取消保持原状态；保存失败不能继续关闭 |
| REQ-014 | 恢复草稿独立备份未保存内容；异常退出后提示恢复，不自动覆盖磁盘；新建未命名文档同样保护 |
| REQ-015 | 自动保存停止输入约 1000ms 触发，连续输入最长等待 10000ms；中文组合输入完成后执行；未命名文档仅备份 |
| REQ-016 | 覆盖前保护旧字节，正式保存确认后立即记录新字节；同组自动节点在固定60秒内合并，手动保存固定节点；提供列表、中央只读查看及原始字节另存；浏览绝不改变当前正文。禁止普通预览覆盖当前文件；仅允许REQ-028明确确认、强制备份和冲突检查的受控还原例外 |
| REQ-017 | 浅色、深色、跟随系统，以及字号、行距、阅读宽度设置持久化；配置损坏回退默认值并提示 |
| REQ-018 | 最近文件、窗口位置尺寸、阅读位置持久化；窗口恢复在可见屏幕内；历史路径失效可移除 |
| REQ-019 | 文件删除、替换、重命名、权限不足、磁盘写入失败有对应行为；保留内存及可用恢复稿，不静默创建被删文件 |
| REQ-020 | 支持系统“打开方式”、冷启动与已启动时打开；不强制设置默认程序；多文件输入时让用户选择一份 |
| REQ-021 | 网络默认关闭；脚本与字体随包分发；文档不能执行脚本/代码、直接访问 Node 或任意磁盘资源 |
| REQ-022 | 可以清空最近文件、恢复记录、历史版本；三类数据分别清理，清理前显示影响范围 |
| REQ-023 | 大文件按阈值降级或拒绝；保留取消入口，耗时提示不伪装成空白成功 |
| REQ-024 | 标准菜单、平台快捷键、键盘可达操作、明确焦点和可读对比度；关闭按钮和系统菜单行为一致 |
| REQ-025 | 打包产物具备版本和架构标识；发布说明、第三方许可、签名/公证与双平台证据齐备 |
| REQ-026 | 最多20个真实文档标签；按规范文件去重，各自保留正文、模式、滚动、选区和历史；关闭/后台错误按文档隔离 |
| REQ-027 | 产品界面使用简洁、真实、就地的状态与错误文案；不展示阶段或技术实现，不虚报已实现能力 |
| REQ-028 | 将校验通过的历史还原到当前文件：默认取消确认，先保存当前dirty并强制保留还原前版本，使用同一写入队列/磁盘版本检查/原子写入；成功为可撤销的新修订。失败保留内容，不能跳过历史备份；相同内容不产生新修订或额外写入 |
| REQ-029 | 当前文档可进入系统原生全屏连续阅读演示；正文快照只读，隐藏标签和普通侧栏，支持滚动、临时目录及Esc退出；退出恢复原模式、面板和位置，原有全屏状态保留 |

## 5. 数据保留与容量

| 项目 | 规则 |
| --- | --- |
| 恢复调度 | 内容变化后空闲 2000ms 备份，连续输入每 10000ms 尝试一次；输入法组合中延后至提交；可接受的丢失窗口是最近一次成功快照之后的内容 |
| 恢复容量 | 每会话保留最新两份完整校验通过的快照；活跃会话不因过期清除；未恢复会话 30 天，最多 20 个会话、合计 100MiB |
| 恢复淘汰 | 达到容量先提醒，清理已处理记录，再清理最旧非活跃记录并显示清理数量；活跃快照无法落盘时持续警示，不报告备份成功 |
| 历史容量 | 每文件最多100条且最长30天，全局200MiB；包含未索引/清理失败的物理正文占用。按提交顺序淘汰最旧未保护节点，连续同内容去重，A→B→A保留；固定不等于永久保留 |
| 历史合并 | 每次成功保存立即记录；同会话、同路径最新自动组从首次记录起60000ms内替换最新节点，恰好边界/时钟回拨新建。手动保存、关闭、另存、还原固定节点；重开/epoch变化不跨组。无修改不新增，但干净手动保存可固定自动节点或补记上次失败。中间自动状态不全部保留 |
| 图片 | PNG/JPEG/GIF/WebP；APNG、SVG与远程内嵌图片不加载；动图总帧像素≤40MP；每会话最多2000条资源授权；单资源最多 20MiB，解码像素最多 40MP，文档一次会话累计读取图片最多 100MiB；SVG 不加载 |
| 文档 | ≤2MiB 正常编辑；>2MiB 且 ≤10MiB 只读纯文本降级；>10MiB 拒绝载入并提示使用其他工具；按字节在读取前后检查 |

MiB = 1024 × 1024 字节。图片在单图压缩字节预算内读取完整压缩输入并检查元数据；无法安全确定尺寸或总帧预算时拒绝授权。UTF-8 字节数与编辑器字符数不混用。

## 7. 行为约束

### 标签与正文

每标签独立保留阅读/编辑模式、选区、撤销、滚动和目录/历史开关；同一规范路径或文件身份只有一个可写会话。关闭最后一标签回欢迎页，本版本不恢复跨重启标签与撤销栈。现行正文为 16px / 1.75 / 最大 1080px；宽度不足时重排。

普通目录与历史为非模态侧栏：最大 280px / 300px，均不超过有效视口 30%；≥960px 可并排，更窄时一次展开一侧。宽屏利用两侧留白保持正文位置；窄屏为侧栏分配宽度，正文仍可滚动、选择、编辑。历史预览保留一份活动快照，隐藏列表与退出预览是不同操作。

### 历史、恢复与还原

欢迎页仅在有待处理恢复记录时显示恢复入口；启动、返回欢迎页及处理记录后重新扫描。失败显示错误并保留菜单备份入口，不能当作零条。

历史保存后立即记录，固定 60000ms 自动组从首次节点起计时，恰好边界和时钟回拨新建；手动/关闭/另存/还原固定节点，不跨 epoch/路径/重新打开合并。连续同内容去重，A→B→A 保留轨迹。固定不代表永久保存，仍服从容量与保留期。

正文保存成功但后置历史失败/被明确跳过，分别展示“正文已保存”和历史警告，不伪造 dirty，不回滚正文；暂停后续自动保存，允许明确手动补记。关闭时额外默认取消确认。历史清理失败独立警告并按物理字节计费。

还原仅对正常可编辑、≤2MiB、磁盘状态 current、无待确认恢复稿的来源开放。默认取消确认，先保护当前 dirty 内容，再写目标历史；任一步历史保护失败不得跳过。保持当前 BOM/EOL，末尾换行取历史文本，按当前格式重查容量。成功为原 CodeMirror 状态中的可撤销新修订，不删除较新历史，不恢复图片副本。部分成功与结果未明分别报告，原请求可核对，不允许伪造修订号解锁。

### 链接与图片

本地图片及本地图片文字链接普通单击打开；其他文字链接使用 macOS Command / Windows Ctrl + 单击或相应修饰键 + Enter。主动链接支持父目录、绝对路径与 file: 单目标，直接解析而不弹额外 picker；不授权父目录，不扩大被动图片范围。附件含 PDF 只定位选中，目录在系统文件管理器打开；HTTP/HTTPS 与 mailto 交系统应用，不由 InkNest 下载。

图片查看支持适应/100%、按钮/捏合/平台修饰键滚轮缩放、顺时针90°旋转、同文档切图、Esc/遮罩关闭和原生滚动，不拖动平移。通常缩放范围10%–400%，极大图下限可取更小的适应倍率；切图/关闭重开恢复初始方向和适应模式。独立行空 `<a id="name"></a>` 的实际支持形式以[交互规格](interaction.md)的受限语法为准；它仅提取锚点，不开放 raw HTML。

### 主题、系统打开与搜索

首次主题跟随系统；64×28px 太阳/月亮胶囊手动选浅/深后全局持久化，200ms 过渡，减少动态效果时停用动画；切主题不重建文档。完整设置页与重新跟随系统入口保留为后续目标。

系统打开在 renderer 订阅就绪后交付；冷/热/第二实例复用同一注册表和关闭准入，重复打开保留会话与撤销。一次多个文件先选一份；不强占默认程序。macOS 包声明 md/markdown，Windows 安装器关联及原生验收仍待完成。

Cmd/Ctrl+F 开关当前来源搜索，打开不自动跳转；输入查询或导航后定位。查找/替换页签位于右上浮层，显隐不挪动工具栏，空间不足只下移浮层。阅读搜索净化正文，编辑搜索源码，历史/演示搜索各自固定来源；分屏目标待实现。支持 Aa、完整计数、非重叠字面匹配、循环导航，查询不跨行、不支持正则。只有编辑模式可当前/全部替换；全部替换单次可撤销，容量/只读/冻结/IME/保存保护不变。

Windows 安装为可选目录的 NSIS 向导，保留安装前取消；卸载保留应用数据，安装目录不得混用文档目录。安装器与内嵌卸载器均需 CRC 检查，不以静态检查代替实机验收。
