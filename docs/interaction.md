# 交互与页面规格

本文说明界面操作及异常处理。产品要求见[需求](requirements.md)，不支持的功能见[已知限制](known-issues.md)。

## 窗口与标签

窗口默认 1200×800、最小 800×600。macOS 为合并标题栏并保留系统按钮位置；Windows 为原生系统边框加内部标签。单窗口最多 20 个真实文档标签，同文件复用，超过上限拒绝新增而不影响原文档。标签栏“+”返回首页，由用户选择打开或新建；首页不创建会话、不占文档名额，重复点击不增加标签。标签栏不放“打开…”按钮，文件菜单和 Cmd/Ctrl+O 仍可打开。标签横向溢出时隐藏滚动条，支持滚轮、触控板和方向键/Home/End，并自动展示活动标签。

已有文件默认阅读。编辑/预览切换保留源码、选区、撤销与滚动；回到预览请求最新保存，不等待写盘即可显示当前内存内容。关闭最后一标签回欢迎页。返回首页前结算 IME，失败保留原视图；成功聚焦首页左侧“新建文档”，右侧为“打开文档”，键盘顺序与视觉顺序一致。所有已有标签保留正文、模式、选区、撤销和滚动，后台保存与草稿备份继续。首页所有文档标签不选中，首个标签可通过 Tab 聚焦；点击文档标签继续原会话。只在发现待处理恢复记录时显示恢复入口，菜单备份管理始终提供救援入口。

当前只有阅读与编辑，不展示未实现的分屏和最近文件入口。每标签独立保留目录/历史开关和书签；重新打开应用不恢复这些状态。

## 正文、目录与历史布局

默认正文 16px、行高 1.75、最大宽度 1080px。正文滚动宿主与内容宽度分开；历史关闭时滚动条到窗口右缘，打开时到历史左缘。

目录最大 280px、历史最大 300px，各不超过视口 30%。空间充足利用留白保持正文位置；不足则侧栏与正文并排分配宽度，允许正文重排，但不遮罩正文、不阻止选择/编辑。≥960px 可并排两侧，<960px 一次展开一侧。目录跳转与历史预览不自动收起列表；窄屏可用历史预览工具栏重新展开列表，不先退出预览。

目录按当前阅读/源码/历史来源定位。标题折叠和列表滚动按来源保留，编辑定位走原编辑器事务；>2MiB 纯文本降级不生成目录。历史列表关闭与退出历史预览分开处理。

## 查找与替换

Cmd/Ctrl+F 开关右上角非模态面板，打开仅聚焦并保留正文位置；已有单行选区≤256字符时可作为初始关键词。输入查询或主动导航才定位。显隐不挪动编辑/历史工具栏，空间不足只把搜索浮层移到下一行。

面板为“查找 / 替换”页签，替换仅在可编辑源码中可用；页签支持方向键/Home/End。计数在输入框内，Aa 切换大小写，Enter/Shift+Enter 上下导航；Mac Cmd+G/Cmd+Shift+G、Windows F3/Shift+F3 同样导航。Esc 关闭当前搜索并归还焦点，模态对话框优先处理自己的 Esc。

查询为字面、非重叠、单行匹配，非正则。阅读仅搜索净化正文，编辑搜索 Markdown 源码，历史/演示搜索所看来源，图片错误占位和工具栏不计入正文。结果完整计数，后台异步取消后不接纳旧来源结果。查询 IME 合成中暂停扫描与动作。

替换当前或全部都通过原 CodeMirror 事务，全部替换一次可撤销；冻结/只读/组合输入/超容量/来源变化时拒绝或取消，不部分写入。成功进入原自动保存、恢复和历史流程；“匹配内容与替换文本相同”不产生无意义修改。

## 保存、另存与冲突

状态分别表示已保存、待保存、保存中、失败、外部变化、恢复备份和历史警告。较旧快照的成功不能清除新修改；恢复已备份不等于正式已保存。标签栏只承载标签、首页入口和主题等窗口操作。当前文档工具栏按“目录、文件名、保存、编辑/预览、演示、历史”排列；保存采用图标加文字，首次为“保存…”，已有路径为“保存”，进行中为“保存中…”。文件名超长时省略，悬停显示完整路径或未命名名称；保存按钮的可访问名称包含当前文档名，悬停提示平台快捷键。工具栏空间不足时分为文件名/保存与目录/视图操作两行。

保存旁的下拉提供“另存为…”和“关闭当前文档”；支持 Tab、方向键、Home/End 与 Esc，Esc 关闭菜单后归还触发按钮焦点。点击外部、切换标签或文档进入受保护操作时收起菜单。保存/另存绑定动作发起时的文档，输入法等待后来源已切换则取消手动保存意图，不能把它转给新标签。后台文档的迟到保存结果只更新该文档。Cmd/Ctrl+S、Cmd/Ctrl+Shift+S 与文件菜单保留。

底部状态栏以图标和文字展示当前文档状态，窄屏省略时可悬停查看完整文字；错误处理继续就地显示在通知区。首页隐藏文档工具栏与状态；只读、冻结及保存事务进行中禁用保存，允许复制的只读文件仍可从下拉另存。历史预览替换整条文档工具栏，使用自己的历史导出入口。

自动保存默认开启：空闲 1000ms、最长等待 10000ms，IME 提交后执行；失败/冲突/历史异常暂停，明确手动重试或解决后恢复。未命名会话只进行独立恢复备份，不自动挑选正式位置，也不因切预览弹出选择器。

另存为通过当前文档保存下拉、文件菜单、Cmd/Ctrl+Shift+S 或救援入口；成功才迁移正式路径与资源基准，保留文档身份和撤销。已有正式路径跨目录另存时提示相对图片/链接会按新目录解析，不复制附件。目标已打开则拒绝。有效 UTF-8 的 permission/link 只读文档可另存普通副本；异常编码/换行与大文件禁用另存，不提供转换或复制操作。

外部干净变化重载并提示；本地有修改则保留内容，提供只读磁盘版本、另存、使用磁盘和明确覆盖。后两者原生确认默认取消，确认后仍重查版本。文件丢失/权限失败不当作空文档，不静默重建。

## 关闭保护

单标签关闭先交换并冻结最新状态，等待已接纳写入，dirty 走 close 保存；失败可取消、重试、另存或再确认丢弃。丢弃只影响未正式保存的内容，持久标记成功后才释放；不回滚之前的自动保存。

整窗退出先冻结全部，再逐个核对/保存，全部维护成功并复核成员和快照后才释放。任一失败/冲突/需要另存则取消退出并定位相关标签，已经成功保存的其他标签不回滚。整窗不提供批量丢弃。还原/生命周期对话框进行中不能绕过门控。

正文已保存但历史失败的关闭另有默认取消确认；未知结果不能假装 dirty 或成功。5秒快照挑战失联保留会话。系统强杀只能依靠已有完整恢复快照，不假定退出回调必定完成。

## 恢复与历史

恢复记录展示文件名、快照时间、可用性，可只读预览、恢复和丢弃；没有原会话授权的恢复预览不借用当前文档图片权限。恢复不覆盖磁盘；来源已打开先激活原标签并要求处理后再恢复，保留恢复记录。

历史列表按保存记录展示，可查看与受控还原；中央预览只读，工具栏提供返回当前、历史另存和历史列表开关，避免重复还原入口。当前最多保留一份历史正文，切标签退出历史预览。图片使用当前正式路径中的资源，不保证还原到历史图片外观。

历史被自动合并后，已显示旧预览保持原内容，提示失效并禁用该 ID 的还原/导出。还原默认取消确认，先保存当前 dirty 并强制保留还原前版本，再写目标；成功可以撤销。丢回执时保留“核对还原结果”，暂时保护源编辑，其他标签仍可操作。

## 链接与图片

普通图片和本地图片文字链接单击打开；其余文字链接使用 Mac Command / Windows Ctrl + 单击或修饰键 + Enter，普通点击/中键/双击/拖选不派发。远程图片文字链接交默认浏览器，不加载进应用。

主动本地 Markdown 链接新增/激活标签，附件含 PDF 在文件管理器定位，文件夹打开自身。父目录/绝对/file: 只授予单目标，不弹额外选择器、不扩大被动资源根。错误显示 2.5秒浮层，重复重置计时，不进入正文布局。

标题片段支持中文、重复后缀和应用 ID。显式锚点只接受独立行空 `<a id="name"></a>` 或 `<a name="name"></a>`（单/双引号、受限无控制字符名称），不接受额外属性/内联 HTML，代码块内原样显示。

查看器支持适应窗口、100%、按钮缩放、同文档切图、Esc/遮罩关闭和双击切换适应/100%。被动图片路径越界显示占位，合法本地目标可主动“打开图片”；地址内误含标题有独立解释，不静默修改 Markdown。

触摸板双指捏合连续缩放，无需按键；鼠标使用 macOS Command / Windows Ctrl + 滚轮缩放。普通滚轮和双指滑动保持原生双轴滚动，不拖拽平移、不带动背景正文。图片视口之外的修饰键滚轮只阻止页面缩放。Mac 同时兼容 Ctrl 标记的捏合/滚轮事件。

指向图片时围绕指针位置缩放，留白处或按钮操作以当前可见图片中心为基准；受滚动边界限制时就近显示。按钮每次增减25个百分点，手势连续按比例调整。通常范围10%–400%；适应倍率小于10%时，下限取适应倍率，小图不自动放大。旋转/窗口变化后已有手动倍率低于新下限时保持原值、禁止继续缩小、允许渐进放大。有效手动缩放退出适应模式，零增量或已达边界不切换模式。

“顺时针旋转90°”每次增加90°，四次回到初始显示方向（包含图片已有EXIF方向）。适应模式旋转后重新完整居中显示；手动模式保持倍率及视口中心对应的图片位置，边界处允许必要偏移。适应、100%、双击及窗口变化保留角度；切图或关闭重开恢复初始方向和适应模式。缩放和旋转不重载当前图片、不改写图片或Markdown，不产生保存与历史。加载中/失败时禁用操作，关闭/切图取消待执行更新。按钮可通过Tab聚焦和Enter/Space触发；平台缩放提示可通过图片视口的无障碍描述读取。

## 主题与演示

标签栏右侧 64×28px 太阳/月亮胶囊切换浅/深，首次跟随系统；手动后持久化。200ms滑块/全局颜色过渡，减少动态效果时停用；失败说明本次生效但下次可能不保留。没有恢复跟随系统按钮或完整设置页。

演示是系统全屏连续阅读，等待原生确认，独立只读快照/滚动/临时目录；不是幻灯片。隐藏普通标签/侧栏，Esc退出并恢复原模式和位置，原本已全屏则保留系统全屏。来源关闭、迁移/epoch失效或不再是展示来源时退出；保留原会话保存保护。

## 功能边界

拖放、分屏、格式转换、最近文件和完整设置没有界面入口。任务框只读；代码高亮与复制见下节。

## Markdown 扩展阅读

关联 REQ-002/004/005/007/016/021/023/024/029/030。支持范围和容量见[Markdown 兼容性](markdown.md)。普通阅读、历史预览、恢复草稿预览和演示统一显示图表、公式、任务列表、脚注、提示块与折叠区。代码工具栏提供语言和“复制”；图表增加“查看源码/查看图表”“原始大小/适应宽度”。错误就地保留源码，任务框仅显示状态。脚注单击或 Enter/空格跳转并聚焦引用/注释，返回链接回到对应引用；其他文字链接仍使用修饰键。

折叠摘要可用键盘展开；目录跳转到折叠区内标题会展开其父区。阅读搜索只索引显示中的正文与图表/公式文字，排除控件、隐藏源码和关闭的折叠正文；内容展示变化后重建当前来源索引。源码、保存状态和撤销不因上述动作改变。


## 新建与首次保存

关联 REQ-008/009/010/013/014/015/016/024/026/027。欢迎页“新建文档”、文件菜单或 Cmd/Ctrl+N 创建“未命名-N”，激活编辑并聚焦第一行。连续按住快捷键忽略自动重复；每次独立动作创建新标签，最多 20 个。切换前等待原标签 IME 提交，不能结算则保留原内容和焦点。演示、原生对话框、关闭或历史还原期间禁止新建。

正文从空字符串开始，不插入标题或示例。只有 text === '' 算空白，空格和换行也受关闭保护；空白不显示修改圆点，始终显示“尚未保存到文件”。草稿待备份、已备份和失败分别显示，不冒充正式已保存。

当前文档工具栏“保存…”、Cmd/Ctrl+S 或另存为均使用原生“保存 Markdown 文档”选择器，建议“未命名-N.md”。初始目录取本窗口最近成功打开/保存的目录，否则使用系统文稿目录。无后缀补 .md；显式其他后缀要求修正。取消恢复编辑与焦点，成功在原标签改名并同步工具栏文件名；首次建立路径不提示目录改变。读写失败和结果未明保留内容，结果未明通过“重试”核对原请求。

无路径时相对图片提示“保存文档后可加载相对路径图片”，相对链接提示先保存；文内锚点、外链和显式单目标绝对链接继续沿现有规则。历史显示“保存为文件后开始记录历史版本”。首存后按新目录重新解析资源并记录历史。

关闭全新空白直接回到其他标签或欢迎页；曾备份后清空须先结算恢复维护。关闭非空未命名稿原生询问保存、不保存、取消，默认取消；选择保存成功后继续关闭，选择不保存还需独立确认，持久丢弃失败保留标签。关闭整窗遇到非空未命名稿停止退出，定位并提示“请先保存或关闭此文档，再退出”，不连续弹出多个保存选择器。
